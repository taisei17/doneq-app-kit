# タスク一覧のまとめ（task-glance）

Doneq の外部アプリ（コミュニティアプリ）のサンプルです。

- 状態ごとのタスク件数（未着手・実行待ち・実行中・承認待ち・完了・失敗）と、期限切れの件数を表示します
- タイトルを入力してタスクを1件追加できます
- このアプリ専用のメモを Doneq に保存・復元できます

アプリ名・アイコン・バージョン・「更新を確認」は Doneq が画面上部の共通ヘッダーとして描きます（`doneq-app.json` の `name` / `icon` / `version` を表示）。
そのためこのサンプルは、アプリ名の見出しや版表示を自前で作らず、画面を操作と内容から始めています。

## 使う権限

| 権限 | 用途 |
|---|---|
| `tasks:read` | 件数の集計のためにタスク一覧を読む |
| `tasks:write` | タスクを追加する |
| `storage` | メモを保存する |

## 試し方

このフォルダを手元に置き、Doneq の「アプリを追加」→「アプリを追加する」→「ローカルフォルダから追加（開発者向け）」→「フォルダを選ぶ」でこのフォルダを選ぶと追加できます（macOS の Finder。絶対パスを直接入力してもかまいません）。
Doneq の「アプリを追加」→「自分でアプリを作る」（開発者ガイド）の「サンプルを追加して試す」からも、Doneq に同梱されたこのサンプルを追加できます。
